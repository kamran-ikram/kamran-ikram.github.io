## Put it online with GitHub Pages

1. Create a repository named `yourusername.github.io`.
2. Upload every file in this folder.
3. Open Settings, then Pages. Under "Branch", choose `main` and save.
4. After a few minutes the site is live at `https://yourusername.github.io`.

To change something later, edit the file on GitHub and save. The site updates on its own.
